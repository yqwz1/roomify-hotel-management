# AI Finance Tasks

## Feature
AI Revenue Forecasting & Pricing Advisor

## Goal
Build a demo-ready AI feature for Roomify that predicts future hotel revenue and occupancy using a lightweight machine learning model, then generates pricing recommendations for room types.

## Person A responsibilities
- DB/migrations.
- Demo data seeder.
- AI Finance APIs.
- Training data endpoint.
- Python FastAPI service.
- ML model training.
- Spring Boot integration.
- Safe demo fallback.
- Security.
- Backend testing.
- API contracts.
- Backend/AI documentation.

## Compressed 3-day execution
- Day 1: DB + config + demo data seeder.
- Day 2: Analytics APIs + training data endpoint + FastAPI ML service + model training.
- Day 3: Spring integration + fallback + Ask endpoint + testing + docs + final rehearsal.

FastAPI, ML, fallback, testing, and documentation stay inside the compressed 3-day scope and are not deferred beyond Day 3.
